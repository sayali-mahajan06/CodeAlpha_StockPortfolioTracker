# CodeAlpha Stock Portfolio Tracker

## 📌 Project Description

This project is a simple Stock Portfolio Tracker developed using Python. It allows the user to enter stock symbols and the quantity of shares they own. The program uses predefined stock prices to calculate the total investment value.

## 🎯 Features

- Allows the user to enter stock symbols
- Allows the user to enter the quantity of shares
- Uses a predefined dictionary for stock prices
- Calculates the value of each stock
- Calculates the total investment value
- Handles unavailable stock symbols

## 🛠️ Technologies Used

- Python
- Dictionaries
- Loops
- Conditional statements
- User input
- Basic arithmetic

## 💰 Available Stocks

The program uses predefined prices for:

- AAPL
- TSLA
- GOOGL
- MSFT
- AMZN
